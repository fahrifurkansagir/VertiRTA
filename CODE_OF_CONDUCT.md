# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in the
**VertiRTA** community a harassment-free, professional engineering experience
for everyone, regardless of background, experience level, or affiliation.

## Our Standards

Examples of behavior that contributes to a productive technical community:

- Focusing on verifiable technical evidence, reproducible benchmarks, and safety
  engineering rigor.
- Giving and accepting constructive code and architecture review gracefully.
- Respecting license boundaries (Apache-2.0, DCO 1.1, zero-GPL runtime lock)
  and original authorship attribution (`NOTICE`).

Examples of unacceptable behavior:

- Harassment, personal attacks, trolling, or derogatory comments.
- Submitting unverified, low-effort automated spam pull requests or fabricated
  benchmark/certification claims.
- Disclosing unpatched security vulnerabilities publicly instead of following
  [SECURITY.md](SECURITY.md).

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be
reported privately via the repository security/maintainer contact on
[github.com/fahrifurkansagir/VertiRTA](https://github.com/fahrifurkansagir/VertiRTA).
Project maintainers retain the right to remove, edit, or reject comments,
commits, issues, and pull requests that violate this Code of Conduct or the
project's technical governance in [CONTRIBUTING.md](CONTRIBUTING.md).
