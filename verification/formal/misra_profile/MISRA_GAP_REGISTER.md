# VertiRTA MISRA-Aligned High-Integrity C++17 Static Profile & Gap Register

**Honest Compliance Statement:** This repository enforces a **MISRA-Aligned High-Integrity C++17 Profile** built from open-source `arm-none-eabi-g++ 14.2.1` (`-Wall -Wextra -Wpedantic -Werror -Wvla -Wshadow -Wconversion -fstack-usage -fcallgraph-info=su,da`), `clang-tidy` (LLVM 22), and `cppcheck 2.22.0` (`--platform=unix32 --funsigned-char`), backed by `ESBMC v8.7` bounded model checking. This profile is **NOT full MISRA C++:2023 compliance**. Neither upstream LLVM `clang-tidy` nor open-source `cppcheck` ships official MISRA C++:2023 rule tables (copyright/licensing constraints; full MISRA C++:2023 checking requires commercial tools such as Cppcheck Premium, MathWorks Polyspace Bug Finder/Code Prover, or Perforce Helix QAC).
